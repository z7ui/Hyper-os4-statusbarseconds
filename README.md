# 状态栏显示秒 (StatusBarSeconds)

一个适用于小米澎湃 OS (HyperOS) / MIUI 的 LSPosed 模块，让状态栏和下拉通知栏的时钟显示秒。

## 作者
- Deepseek
- B站 @z7ui

## 功能
- 状态栏时钟显示秒 (HH:mm:ss)
- 下拉通知栏大时钟显示秒 (HH:mm:ss)
- 保持日期正常显示 (MM月dd日 周几)
- 锁屏和息屏显示保持不变

## 环境要求
- Android 13+ (建议 HyperOS / MIUI)
- 已安装 LSPosed 框架

## 使用方法
1. 安装 APK。
2. 在 LSPosed 中启用模块。
3. 作用域勾选「系统界面」(com.android.systemui)。
4. 重启系统界面或重启手机。
